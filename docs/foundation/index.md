# Foundation

Before diving into the tutorials, read the concept pages below. You don't need to be an expert — a basic mental model will make everything click faster.

## Concepts

- **[Tokens](tokens.md)**: the unit everything in AI is measured and priced in
- **[What's in a Request](anatomy-of-a-request.md)**: why one sentence can cost 1,000 tokens
- **[OpenTelemetry](opentelemetry.md)**: the open standard we use to collect observability data
- **[AWS Bedrock](aws-bedrock.md)**: the AI platform our examples run on

!!! note "Complete beginner?"
    Start with Tokens, then OpenTelemetry. Those two are the most important for understanding the tutorials.

## Setup

Once you've read the concepts, work through **[Setup](setup.md)** before starting any hands-on exercise. It covers:

- AWS credentials (no AWS CLI required)
- Dynatrace API and platform tokens
- Choosing your environment (Codespaces, local dev container, or plain Python)
- Verifying the end-to-end pipeline with a smoke test
